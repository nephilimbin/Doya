# 数据库配置指南

> [English](../en/modules/database.md) · 中文

> 管理数据存储连接：默认使用内置 SQLite，个人使用无需任何改动；需要多机共享或已有 MySQL 时再切换。入口：【设置 → 数据库】。本页改动保存后需重启后端生效（换库流程见下文）。

## 默认形态（SQLite，零配置）

开箱即用：数据落在数据目录 `~/.doya/data/doya.db`，无需安装任何数据库软件。备份策略见文末。

## 切换到 MySQL

1. 【设置 → 数据库 → 配置数据库】，「数据库类型」切为 `mysql`
2. 填连接参数：

| 参数 | 默认 | 说明 |
| ---- | ---- | ---- |
| 主机地址 | 127.0.0.1 | MySQL 主机 |
| 端口 | 3306 | |
| 用户名 | root | |
| 数据库密码 | — | 密码框；可填 `${MYSQL_PASSWORD}` 这样的环境变量占位符，值从数据目录 `.env` 或系统环境变量读 |
| 数据库名称 | doya | 仅字母数字下划线，≤64 |

   连接池等高级参数在「高级参数」折叠区，默认值已合理，一般不动。

3. 点「**测试连接**」验证可达（连通但表结构有缺列会给警示提示）
4. 点「**保存**」——涉及数据库定位的修改会弹出**「切换数据库」**三选一：

| 选项 | 语义 | 适合 |
| ---- | ---- | ---- |
| **沿用新库** | 不迁移，直接用新库现有内容；源库数据原地保留，随时可切回 | 新库已初始化过 / 只想换空库重来 |
| **迁移覆盖** | 把源库的**配置族数据**（设置、订阅、模型等，不含文章）搬到新库并覆盖；执行前自动对两边打快照 | 换库但想保留订阅与配置 |
| **从备份恢复** | 选一份配置快照灌入新库，不读源库 | 源库不可达时的抢救路径 |

5. 保存成功后页面出现「配置已保存，重启后生效」横幅，点「**重启**」按钮完成后生效

> 页面保存写入的是数据目录的 `config.local.yaml`（只存你改过的键），运行中的服务仍连旧库，重启后才完成切换；出厂包内的 `config.yaml` 只读不动。

## 备份

「备份」组提供两类快照，均存服务端数据目录 `data/backups/`：

- **配置快照**：设置、订阅、模型等配置族（体积小）
- **全量快照**：含文章数据

| 参数 | 默认 | 说明 |
| ---- | ---- | ---- |
| 配置备份间隔（分钟） | 60 | 0 = 关闭定时 |
| 全量备份间隔（分钟） | 1440 | 每天一次 |
| 配置/全量快照保留数 | 5 / 2 | 超出自动清理 |

行内「**配置快照**」「**全量快照**」按钮可随时手动触发；换库时的「从备份恢复」就选自这里。
