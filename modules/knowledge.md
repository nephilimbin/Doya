# 知识库配置指南

> [English](../en/modules/knowledge.md) · 中文

> 知识库把你采集的文章变成可检索的「情报库」：支持关键词检索与语义混合检索，并可对库里内容做问答式查询。【设置 → 知识库】页分四块：**检索引擎 / 配置模型 / 配置知识库 / 测试检索**。

## 检索引擎

页面顶部显示引擎状态徽章（运行中 / 启动中 / 未运行 / 崩溃退避中）。引擎异常或更换模型后可用「**重启引擎**」按钮；如显示已连接则为正常。

> 未放置本地模型时，引擎退化为**仅关键词检索**(BM25)，知识库功能仍可用——模型是启用语义检索（混合模式）的可选增强。

## 配置本地模型（启用混合检索，可选）

混合检索依赖**三件本地模型**（嵌入 / 查询扩展 / 重排），每件由模型文件与配套校验文件组成——模型目录最终应有 **6 个文件**。两种获取方式：

### 方式一：作者提供的模型压缩包（推荐，解压即用）

1. 下载模型压缩包：<占位：压缩包下载链接 / 获取渠道>
2. 点「**打开模型目录**」（目录为 `~/.doya/models/rag/qmd/models/`；手机等远程访问时请用电脑端操作）
3. 将压缩包内的 6 个文件全部解压到该目录
4. 回到页面点「**检测模型**」，徽章显示「已就绪」即成

### 方式二：自行从 HuggingFace 下载

引擎对文件命名有严格约定，下载后需**重命名**为下列「放置文件名」，并补齐配套校验文件：

| 用途 | HuggingFace 仓库 / 文件 | 放置文件名 | 配套校验文件 |
| ---- | ---- | ---- | ---- |
| 嵌入 | `Qwen/Qwen3-Embedding-0.6B-GGUF` 下 `Qwen3-Embedding-0.6B-Q8_0.gguf` | `hf_Qwen_Qwen3-Embedding-0.6B-Q8_0.gguf` | `Qwen3-Embedding-0.6B-Q8_0.gguf.etag` |
| 查询扩展 | `tobil/qmd-query-expansion-1.7B-gguf` 下 `qmd-query-expansion-1.7B-q4_k_m.gguf` | `hf_tobil_qmd-query-expansion-1.7B-q4_k_m.gguf` | `qmd-query-expansion-1.7B-q4_k_m.gguf.etag` |
| 重排 | `ggml-org/Qwen3-Reranker-0.6B-Q8_0-GGUF` 下 `qwen3-reranker-0.6b-q8_0.gguf` | `hf_ggml-org_qwen3-reranker-0.6b-q8_0.gguf` | `qwen3-reranker-0.6b-q8_0.gguf.etag` |

「检测模型」逐件核验文件存在性与完整性，**6 件齐全才判定就绪**；配套校验文件缺失时不会就绪，且后续同步可能触发引擎重新下载。过程较繁琐，优先推荐方式一。

放置与检测完成后，**无需重启引擎**——下次检索自动启用混合模式；首次检索加载模型约需 20~30 秒，之后正常。

## 配置知识库

知识库以「库」为单位，每个库可圈定不同范围的源：

1. 点「**新建库**」，填写：

| 字段 | 说明 |
| ---- | ---- |
| 库名 | 小写字母/数字开头，仅小写字母、数字、下划线、连字符，≤64，不可重复 |
| 索引内容 | **单向构建**（推荐：每篇择 AI 摘要→提取正文→原文中最优一份，体积与耗时均衡）/ **复合构建**（拼接全部内容，信息最全但体积与嵌入耗时最大） |
| 范围 | 「全部源（动态）」= 自动跟随源列表；或「自定义勾选」指定分类/源 |

2. 点「**开始同步**」构建索引（无勾选时同步全部启用的库；进行中可「停止」）
3. 「启用」列控制该库是否参与检索；不需要的库可删除（索引与向量一并清理，重建需重新嵌入）

**同步周期**（分钟）：默认 720（12 小时）自动增量同步一次；改为 0 停用定时，完全手动。

## 测试检索

页面底部可即时验证：选检索范围（全部库/指定库）、检索方式（自动 / 关键词 / 混合）、结果数，输入查询词（支持 `"短语"` 精确匹配、`-词` 排除），点「检索」；结果可点开阅读原文与相关度。

> 日常情报问答推荐直接用 agent：在「代理」页说「在知识库里检索关于 XX 的信息」，见 [Agent 使用指南](agent.md)。
