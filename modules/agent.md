# Agent（代理）使用指南

> [English](../en/modules/agent.md) · 中文

> 推荐的操作方式：Doya 的主要功能（添加订阅源、调整过滤解析、检索知识库、数据查询等）都可以用自然语言交给 agent 完成，由其调用对应能力代为执行，无需在各设置页间逐项操作。入口：左侧主导航的**「代理」**页（需本机安装 agent 命令行工具，见「前置条件」）。

## 这是什么

「代理」是 Doya 内置的 AI 代理终端：你在网页里与 AI agent 对话，agent 通过内置的 `doya` 命令行直接操作程序。——加源、抓取、过滤、解析、查库、导出订阅，全程对话式完成。

## 前置条件

**本机安装了受支持的 agent 命令行工具**（会自动识别安装的Agent工具，后期会持续增加。）：
- **Claude Code**:[官方安装文档](https://docs.claude.com/en/docs/claude-code/setup)
- **Codex**:[GitHub 开源项目](https://github.com/openai/codex)


> [!WARNING]
> 本Agent **不使用** Doya【设置 → 模型】里配置的 LLM 平台与 API Key——那些是供文章过滤/解析管线使用的。Agent 使用其自身的账号认证及设置。

## 开始使用

1. 打开左侧主导航的「代理」页。
2. 在左栏选择已安装的 agent（未安装的会灰显并提供安装链接；刚装完点「刷新」重新探测）
3. 点 **「新建对话」**，右栏出现终端
4. 直接用自然语言下指令，例如：

| 想做的事 | 对 agent 说 |
| ---- | ---- |
| 添加 RSS 订阅 | 「添加 https：//example.com/feed 这个 RSS 源」 |
| 写一个网站爬虫 | 「给 https：//xxx 写一个 spider 抓取文章列表」 |
| 查知识库 | 「在知识库里检索关于 XX 的说法」 |
| 看运行状态 | 「看下系统状态和各源的健康情况」 |
| 导出订阅 | 「把我的订阅导出成 OPML」 |

会话**常驻**：关闭网页不会杀掉 agent 进程，重新打开页面回到会话可继续（Claude Code 支持恢复；Codex 进程结束即需新对话）。

## agent 能做什么

| 领域 | 能力 |
| ---- | ---- |
| 订阅源管理 | 添加/列出/运行 RSS 与 Spider 源，启停、删除、清数据、健康检查、模板复用；建源含 robots.txt 核查与数据样本确认 |
| 过滤与解析 | 运行过滤/解析，一次性抓网页转 Markdown，查看处理统计 |
| 知识库 | 检索式情报问答（只读） |
| 数据查询 | 只读 SQL 查询（不直连数据库） |
| 订阅导入导出 | OPML 导入/导出 |
| 模型管理 | 列出平台/模型/提示词模板 |
| 系统 | 状态、版本、热重载、路径、schema 查询 |

## 安全边界（agent 的行为约束）

agent 在受约束的环境里工作，以下规则随会话注入：

- **只读写你的数据目录**(`~/.doya/`)，不碰其他位置
- 写操作（下载、删除、写文件）**先演练(`--dry-run`)再执行**；涉及密钥文件（`.env`、`config.local.yaml`）的读写须你确认
- 新建源**先查重**且配置须经你确认才落库
- 偏好与习惯沉淀在数据目录的 `agent/preferences.md`，跨会话保留、升级不丢

## 工作目录

每个 agent 会话工作在 `<数据根>/agent/` 目录（默认 `~/.doya/agent/`）。
「代理」页左栏的「工作目录」按钮可直接打开（仅本机直连时可用；远程访问需前往服务器端操作）。

> [!NOTE]
> 工作目录中的官方内容（`CLAUDE.md`、`.claude/skills/doya-cli/` 等）由「同步官方工具包」经你确认后复制/更新：你可以修改它们，更新弹窗会标出「你的修改会被覆盖」并让你选择更新或保持；你自建的技能与配置产品**永不触碰、永不删除**。`.product-sync.json` 是同步状态记录，勿手改。个人偏好也可写入 `agent/preferences.md`（agent 会自动读取）。

## 常见问题

- **刚装好 agent 工具，页面里还是显示未安装？** 点左栏「刷新」按钮强制重新探测（平时结果缓存 5 分钟）。
- **终端里提示鉴权失败？** 会话显示「[鉴权失败，请重新登录]」时，重新登录 Doya 后新建会话即可。
- **远程（手机/其他设备）访问时能用代理页吗？** 可以对话，但「工作目录」按钮仅本机直连可用。
- **agent 会话会占资源吗？** 空闲会话不消耗算力；长期不用的会话可在会话列表删除。
