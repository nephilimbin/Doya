# 采集源(RSS / Spider)配置指南

> [English](../en/modules/rss.md) · 中文

> Doya 的信息来自两类采集源：**RSS 订阅**与 **Spider 爬虫**。添加和维护在【设置 → 源管理】，抓取节奏与过滤解析行为在【设置 → 源行为】调整。

> [!TIP]
> 添加源这类操作推荐直接交给 agent：打开左侧「代理」页，输入「帮我添加 xxx 的 RSS」即可，见 [Agent 使用指南](agent.md)。手动配置方式见下文。

## 添加 RSS 源

1. 【设置 → 源管理】→ 点「**添加 RSS**」
2. 填写：

| 字段 | 说明 |
| ---- | ---- |
| 名称 | 源的唯一标识，不可与其他源重复 |
| 订阅地址 | RSS 订阅地址（`http(s)://` 开头） |
| 网站地址 | 网站主页地址，用于生成 OPML |
| 分类 | 下拉选择已有分类（分类可在「管理分类」里建） |
| 标签 | 逗号分隔，可选 |
| Cron 表达式 | 抓取节奏，5 段式，默认 `0 */12 * * *`（每 12 小时） |
| 采集上限 | 单次采集条数上限，默认 999 |
| 启用 / 过滤 / 解析 | 三个开关，默认全部开启 |

3. 保存后源进入列表，按 Cron 自动抓取；也可在行内「启用」开关旁手动触发检查。

## 添加 Spider 源

Spider 用于没有 RSS 的网站（需要写 Python 爬虫脚本）。

1. 先把 spider 脚本(`.py`)放到数据目录 `~/.doya/data/spiders/`（脚本写法与模板见 [Spider 管理指南](../spiders.md)）
2. 【设置 → 源管理】→ 点「**添加 Spider**」，除通用字段外填：

| 字段 | 说明 |
| ---- | ---- |
| 执行文件 | spider 脚本文件名（如 `my_spider.py`） |
| URL 模板 | 带 `{key}` 占位符的地址，如 `https://api.x.com/{cat}/list` |
| POST 参数 | 填充占位符的取值(JSON)，默认 `{}` |
| 额外参数 | 传给脚本的参数（JSON，如 cookie、api_token），默认 `{}` |

> [!TIP]
> 弹窗内也有提示：建议通过 agent（skill 工具）添加源——将目标网址提供给 agent，它会代写脚本、核查 robots.txt、确认数据样本后建源。

## 管理已有源

- **启停**：列表「启用」列的开关即点即切；批量勾选后用「启用选中 / 禁用选中」
- **删除**：单源删除或勾选后「删除选中」，弹窗二选一：
  - **仅删除源（退订）**——历史文章保留
  - **源及文章**——级联删除抓取、过滤记录与全部文章，不可恢复
- **分类**：「管理分类」可添加/重命名/删除；删除分类时其下源迁入 `unknown`
- **查找**：类型筛选（全部/RSS/Spider）、搜索框、以及「显示字段」面板（自选显示列与顺序）
- **健康**：「状态」列红色叹号表示最近抓取出错，悬停可见原因；「Cron」列悬停可见原始表达式

## 源行为（过滤 / 解析 / 调度）

【设置 → 源行为】控制所有源的抓取与处理行为，分三组：

### 过滤(Filter)

抓取时的礼貌与并发参数，保存后自动应用（无需重启）：

| 参数 | 默认 | 说明 |
| ---- | ---- | ---- |
| 启用过滤 | 开 | 关闭时会提示「同时暂停解析」 |
| 正文提取算法 | readability | 三选：markitdown（整页转换，最轻）/ trafilatura（纯 Python 提正文）/ readability（Mozilla 阅读视图，需 node） |
| 下载延迟（秒） | 3.0 | 对站点的礼貌间隔 |
| 最大并发 / 每域并发 | 10 / 1 | 并发抓取控制 |
| 批量大小 / 最大重试 | 10 / 3 | 每批处理量与重试 |
| 抓取超时（秒） / 重试 | 30 / 1 次（隔 2 秒） | 单页抓取容错 |

### 解析(Parse)

AI 解析（需先配置模型，见[模型管理](llm.md)）：

- 页面顶部的**「解析模型」**选择器：从已启用平台中选取 chat 模型；切换在下个解析周期生效
- 常用参数：模型温度(0.3)、单次请求超时（100 秒）、每分钟请求上限(60)、移除文章内链接（关；开启可省 token）
- 解析提示词模板在【设置 → 提示词】管理，可按源绑定（编辑源时选「解析模板」）

### 调度(Scheduler)

改完需**重启后端**生效：调度线程数(20)、时区（默认 Asia/Shanghai，可搜索选择）、启动延迟（1 秒）。
