# 模型管理指南

> [English](../en/modules/llm.md) · 中文

> 配置 AI 服务商连接，供**文章的 AI 过滤与解析**调用。入口：【设置 → 模型管理】。平台目录出厂内置（国内外主流云端服务商 + 本地推理引擎），你要做的不是「新增平台」，而是**连接**你有 API Key 的平台。

> [!WARNING]
> 此页与「代理」页的 agent 无关：agent 使用其自身(Claude Code / Codex)的账号认证，见 [Agent 使用指南](agent.md)。

## 连接一个平台

1. 左栏平台列表中选择服务商（可搜索；徽标状态：已配置 / 无法连接 / 未配置，本地平台标「本地」）
2. 右侧「连接配置」：

| 字段 | 说明 |
| ---- | ---- |
| 显示名 | 列表里的名字，失焦自动保存 |
| API 地址 | 默认已填出厂地址，一般不用改（自有代理/私有部署时才改；清空保存 = 恢复出厂地址） |
| API 密钥 | 你从服务商获取的 Key；本地平台(Ollama / vLLM / llama.cpp / LM Studio)无需填写 |

3. 点「**连接保存**」——会**实测连接**，通过才保存（密钥不回显，留空 = 保持不变）

## 添加模型

平台连接后：

1. 点「**获取模型列表**」：自动拉取该平台的全部可用模型（推荐先做这步）
2. 列表没有的模型用「**添加模型**」手动补：填平台官网的模型名即可（自动补全前缀，如 `glm-5.2` → `zai/glm-5.2`）；「测试并保存」会发一次最小请求验证可用（产生极小额费用）
3. 模型行的能力标签(chat / vision / tts / asr / embed)点击可切换，按实际能力标注即可

## 密钥的两种给法

优先级从高到低：

1. **页面直填**（推荐）：「连接保存」即验证并保存，立即生效
2. **自定义环境变量**：「密钥环境变量」处显示该平台的约定变量名（如 `ZAI_API_KEY`）；在数据目录 `.env` 文件里写 `ZAI_API_KEY=sk-xxx`，保存后即时生效（点「去设置」可直接打开 `.env` 编辑；也可用系统环境变量，但那种需重启服务）


## 启用 AI 解析

完成平台连接并添加 chat 模型后，还需指定解析所用的模型，AI 解析才会运行：

1. 前往【设置 → 源行为】，在页面顶部的**「解析模型」**选择器中选定平台与模型
2. 选定后，新模型自下一个解析周期起生效

解析使用的提示词模板在【设置 → 提示词】中管理，可按源绑定不同模板。

## 本地推理引擎

内置四个本地平台，连本机或局域网内自部署的推理服务，无需 API Key（按需改 API 地址指向你的服务）：
Ollama（默认 `http://127.0.0.1:11434`）· vLLM · llama.cpp · LM Studio
