# Doya 安装指南

> [English](en/install-guide.md) · 中文

> 适用于 macOS(Apple Silicon)与 Windows。各功能的详细配置见文末「模块文档导航」。

## 一、Doya 是什么

Doya 是**可自定义信息聚合平台**：把你关心的信息源聚到一起，AI帮你过滤、提炼、检索，主要能力：

| 能力 | 说明 |
| ---- | ---- |
| **多源采集** | RSS 订阅 + Spider 爬虫（自写脚本抓没有 RSS 的网站），按节奏自动抓取 |
| **AI 过滤与解析** | 正文提取、按提示词模板生成摘要等；支持国内外主流 LLM 平台与本地推理 |
| **知识库检索** | 把采集的文章变成可语义检索的情报库，支持问答式查询；可挂本地模型启用混合检索 |
| **AI 代理操作** | 内置代理终端，用自然语言指挥 AI agent 完成加源、调参、检索等主要操作 |
| **阅读器** | 网页端阅读界面；兼容 GReader 协议，可接入手机端第三方阅读器 |

**日常使用版说明**：免费、无时限，限制为最多 **20 个采集源** （已禁用的源不释放名额；达到上限时新增会有明确报错提示，源管理页可查看全部源）；完整版获取方式可联系作者。

## 三、安装

### macOS

1. 双击 `Doya_1.3.0_macOS_arm64_Trial.dmg`
2. 在弹出的窗口里，把 Doya 图标拖到旁边的 Applications 文件夹
3. 打开「应用程序」文件夹，双击 Doya 启动

### Windows

1. 双击 `Doya_1.3.0_Windows_x64_Trial_Setup.exe`，按向导完成安装
2. 双击桌面（或开始菜单）的 Doya 快捷方式启动

## 四、首次运行的安全提示

- **macOS**：首次打开提示「无法验证开发者」属正常。任选其一放行：【设置】→【隐私与安全性】→ 点「仍要打开」；或在「应用程序」里右键 Doya → 选「打开」→ 再点一次「打开」。之后的启动不会再问。
- **Windows**：首次运行弹出蓝色「已保护你的电脑」(SmartScreen)属正常，点「更多信息」→「仍要运行」即可。

## 五、首次使用

1. 双击启动后等约 10~30 秒（首次启动要初始化并解压内置浏览器到数据目录，仅首次较慢），浏览器会自动打开页面（自动开页始终带实际地址；极少数情况下端口被占用会自动改用其他端口）。若迟迟未开页，确认进程在跑：macOS 活动监视器看 `doya.bin`，Windows 任务管理器看 `doya.exe`
2. 登录：出厂账号 admin / admin（首次登录会强制要求修改密码）
3. **推荐先配置 agent，用对话操作软件**——Doya 的主要功能都可以交给 AI agent 完成，无需手动在各设置页操作：
   - 在本机安装 [Claude Code](https://docs.claude.com/en/docs/claude-code/setup) 或 [Codex](https://github.com/openai/codex)（二选一，后期会添加更多Agent工具）。
   - 打开左侧导航 **「代理」** 页，选择 agent → 点「新建对话」
   - 以自然语言下达指令即可，例如：「帮我添加 xxx 的 RSS」「给 xxx 网站写一个爬虫」「在知识库里检索 xxx」——agent 会代为执行
   - 详细说明见 [Agent 使用指南](modules/agent.md)

4. 需要手动配置时，再看对应模块文档：
   - 添加/管理采集源(RSS)→ [采集源配置](modules/rss.md)
   - 编写 Spider 爬虫脚本 → [Spider 管理指南](spiders.md)
   - 配置 AI 模型（过滤/解析用）→ [模型管理](modules/llm.md)
   - 知识库与本地模型 → [知识库配置](modules/knowledge.md)
   - 数据库与备份 → [数据库配置](modules/database.md)
   - 监听地址/端口、手机与远程访问 → [服务入口与远程访问](modules/service.md)

5. 关闭网页不会关闭应用程序。要停止服务，在【设置 → 账户】页点「关机」；平台备用方式：
   - macOS：菜单栏顶部的 Doya 图标菜单（推荐备用通道；「隐藏菜单图标」后，下次服务重启时图标自动恢复）。图标不可用且网页无响应时，打开「终端」：
     - 想恢复服务：`pkill -x doya.bin`（监督循环 2 秒后自动重拉，隐藏的菜单栏图标一并恢复）
     - 想彻底关闭：`pkill -f serve.sh && pkill -x doya.bin`（先停监督循环再停后端，避免被重新拉起；活动监视器等价操作：先退出命令含 `serve.sh` 的 bash 进程，再逐条退出 `doya.bin`，同名多条属正常形态）
   - Windows：右下角任务栏托盘的 Doya 图标右键 →「退出后端服务」（走进程信号不走网页，网页打不开/卡死时也能用；找不到图标见下方第 7 条）。图标不可用且网页无响应时，：
     - 服务卡死想恢复：**再双击一次 Doya**——程序检测到服务未响应会弹窗，点 OK 即自动结束卡死进程并重启（托盘图标随之恢复）
     - 想彻底关闭：任务管理器「详细信息」页，先结束命令行含 `serve.cmd` 的 cmd.exe（监督循环，不先停会把后端重新拉起；默认不显示命令行列：右键列标题 → 选择列 → 勾选「命令行」），再结束全部 `doya.exe`（同名多条属正常，全部结束）
6. 重复双击不会起第二套服务，只会再开一次页面。
7. **Windows 托盘图标**（任务栏右下角）：状态行显示服务运行状态与实际访问地址（点击可直接打开页面），右键可「重启后端服务」「退出后端服务」。看不到图标时点任务栏右下角的 ^（Win11 可在 设置 → 个人化 → 任务栏 → 其他系统托盘图标 里把 Doya 设为开）

## 六、数据目录(`~/.doya`)

所有数据都在用户主目录的 `.doya` 文件夹。 
MacOS: `~/.doya/`;
Windows：资源管理器地址栏输入 `%USERPROFILE%\.doya` 回车即达。
**升级、重装、卸载都不动这个目录**；删除它 = 清空全部数据。

```
.doya/
├── config.local.yaml    # 你改过的设置(设置中心保存时自动写)
├── .env                 # 密钥文件(可选,装好模型密钥后自动生成)
├── data/
│   ├── doya.db          # 主数据库(订阅、文章、账号、设置;体积大头)
│   ├── backups/         # 自动/手动备份快照
│   ├── spiders/         # 你的 spider 爬虫脚本
│   └── knowledge/ 等    # 知识库镜像与检索索引
├── logs/                # 运行日志(按日新文件,自动保留 30 天)
├── models/              # 知识库本地模型(放入三件套后启用混合检索)
├── agent/               # agent 会话工作区与偏好记忆
├── browsers/            # 内置浏览器首启解压(macOS/Windows)
└── run/                 # 运行时状态(PID/端口等,可随时删)
```

要点：

- **备份**：先退出服务再复制——程序运行时数据库正在写入，直接复制可能得到不完整的副本。整份复制 `.doya` 目录最稳妥；空间有限时至少备份三样：`data/`（全部数据，订阅、文章、账号都在里面）、`config.local.yaml`（设置中心改动的参数）、`.env`（模型密钥）。`models/` 体积大且可重新放置，`logs/`、`run/` 是运行痕迹，可不备份
- **迁移**：换电脑时，退出服务后把整个 `.doya` 目录复制到新电脑的用户主目录下，直接启动即可；若想放在主目录以外的位置（如其他磁盘），复制过去后设置环境变量 `DOYA_DATA_DIR` 指向新路径再启动（程序默认只在用户主目录找 `.doya`）
- 遇到问题时，`logs/` 目录的日志里通常有具体的报错原因（每天一个文件，自动保留 30 天）；向作者反馈时附上报错的那几行，能更快定位（反馈入口见文末）

## 七、卸载

> **卸载不会动你的数据**：卸载只是移除程序本身。想保留数据(如打算
> 重装)就什么都别删；想彻底清空才删除数据目录，**删除后无法恢复**，
> 请先确认里面没有需要留存的内容。

- **macOS**：删除应用程序里的 Doya；数据目录按需删除。若开过「开机自启」，建议先在设置里关掉再删——不关也不影响数据，只是会残留一个失效的开机启动项（登录时系统记一条启动失败日志，无弹窗、不会反复重试）；已删了 app 想补清理的，手动删除 `~/Library/LaunchAgents/com.doya.server.plist` 即可
- **Windows**：若开过「开机自启」，**先在设置里关掉**再卸载（卸载程序不清理该注册项，残留会导致每次登录弹「找不到脚本文件」提示）；然后设置 → 应用 → 卸载 Doya（卸载完成时会提示数据目录位置）；数据目录按需删除

## 八、升级

- **macOS**：下载新 dmg，把新的 Doya 拖进 Applications 覆盖旧版即可。旧版若正在运行，会在约 30 秒内检测到新版并自动优雅退出（弹通知告知），双击图标启动新版即完成升级——无需先手动退出旧版
- **Windows**：运行新 Setup.exe 覆盖安装。安装器会检测运行中的 Doya 进程并引导结束（清场页面），按向导操作即可

数据均不受影响。
